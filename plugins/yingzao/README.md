# 映造

启用后使用映造工作流、审美检索和自审设计流程；内部 API 独立开关，密钥只在本机设置中保存。

丫鸭显示在桌面，支持拖动、点击审美库及拖入原图。右键打开设置；大小、透明度、置顶、位置锁定和喂图选项实时生效。

个人审美、记忆和素材仅保存在插件本地资料目录。包体审美库与本地库联合检索；不使用 Cloudflare 云库。

设置中的“本地资料与更新”提供目录快捷入口及运行时更新、回退。更新校验签名与文件哈希，保留本地资料；重新连接后生效。

安装和许可说明：[映造公开分发仓库](https://github.com/leovyy/yingzao-plugin)。

0.7.6修复旧包缺少baoyu/LICENSE、内部API关闭时未接入宿主工作流、短租约和恢复参数不明确等问题。常用设置统一在Codex原生插件设置；丫鸭打开紧凑收藏窗口。

插件自带MCP配置，正常安装后无需手动添加服务器。消息钩子须在Codex中审阅并信任；当前聊天未重新加载或钩子未信任时，不能认定相关工作流规则已经自动生效。此GitHub桌面版本不等于已上架OpenAI官方公共目录。

内部API默认关闭；正常宿主分析、检索、参考识别、代码与本地制作不受其配置影响。只有手动选择或真实确认宿主缺少所需生图工具时才检查内部服务，能力回退限本次任务，不改变默认开关。全库重分析在本机保存新版观察及旧分析历史，包体结果存本机覆盖层，个人选择与删除状态保留。
